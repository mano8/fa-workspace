# Git Conventions

## Commits

- NEVER mention `co-authored-by` or any similar attribution - never mention the tool used to create the commit message or PR
- Always check git status before committing
- Never create a new branch unless the user explicitly asks for one.
- Never push directly to main.

## Branches

- Branch names should be descriptive and kebab-case

## Pull Requests

- PR description must be wrapped in a fenced ```markdown block so it is directly copyable
- NEVER mention `co-authored-by` or the tool used to create the PR
