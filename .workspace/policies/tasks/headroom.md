# Headroom task

When the installed tool inspection confirms Headroom is available, use
compression for large non-secret logs, test output, search results, JSON,
stack traces, file excerpts, and build output. Retrieve original content only
when exact details are needed; inspect statistics only when savings or state
matter. External processing must follow
[`SEC-NO-SECRET-DISCLOSURE`](../../architecture.md#sec-no-secret-disclosure).
